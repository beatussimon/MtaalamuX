# MtaalamuX

A Django-based platform connecting experts with clients, featuring professional profiles, articles, jobs, and more.

## Features

- Professional profiles with verification
- Article publishing and commenting
- Job posting and management
- Messaging system
- User reviews and ratings
- Dark/Light theme toggle
- Responsive design with Bootstrap 5

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run migrations: `python manage.py migrate`
4. Create superuser: `python manage.py createsuperuser`
5. Run server: `python manage.py runserver`

## Testing

Run tests with: `python manage.py test`

## Deployment

Set DEBUG=False and update SECRET_KEY for production.
